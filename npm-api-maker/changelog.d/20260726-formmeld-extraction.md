Removed API Maker's generic Form framework in favor of `formmeld@^0.1.1`. This is a breaking change: migrate API Maker form imports to `import {Form, FormInputs, useForm} from "formmeld"`. API Maker no longer exports these APIs and no `build/form` compatibility path remains. Checkbox values owned by `FormInputs` are now consistently boolean (`false`/`true`) even when HTML submission uses hidden `"0"` and checked `"1"` values; migrate consumers that compared FormInputs values with numeric `0` or `1`.
