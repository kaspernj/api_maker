Generated frontend models now report a column default with the type the column actually has. The database literal used to be serialised verbatim, so a boolean default came out as `"default": "false"` on Postgres and `"default": "0"` on SQLite — truthy strings that contradicted the `"type": "boolean"` reported in the same block. Integer defaults are numbers again, string defaults are unchanged and a column without a default is still `null`.
