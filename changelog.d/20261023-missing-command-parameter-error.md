A command payload that omits a required parameter (for example an update command without the model key, so the resource's `params.require(:model)` raises `ActionController::ParameterMissing`) no longer escapes as a reported production error. The command now answers with a dedicated per-command error (`type: missing_parameter`) naming the missing parameter, the rest of the batch runs normally, and the rejection is logged with request attribution plus a process-wide counter instead of being reported as an application error.
