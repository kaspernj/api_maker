Added `ApiMaker::ForceJsonAcceptMiddleware`, installed by the ApiMaker railtie at the front of the middleware stack, so every app that mounts the engine negotiates its requests as JSON. A request reaching `/api_maker` with an HTML Accept was negotiated as HTML, so an auth failure there answered Devise's HTML sign-in redirect instead of a JSON error, and the client rejected the whole command batch with "Expected JSON response from /api_maker/commands but received string". Apps no longer need their own copy of this middleware (Nemoa had one).
