Fixed malformed `/api_maker/commands` payloads: the command pool is now validated before any command runs — every level down to each command entry must be a Hash. A String, Integer or other non-Hash payload returns 400 with the offending path and received class (`type: malformed_command_request`) instead of crashing mid-iteration with a 500 (`undefined method 'each' for String`, `no implicit conversion of Symbol into Integer`). Each rejection logs a redacted snippet (class plus truncated inspect, never the full body) with request path/method/user-agent and bumps a process-wide rejection counter (`ApiMaker::CommandRequestExecutor.malformed_request_count`) so repeated bad payloads stay observable without creating bug reports. Websocket requests get the same error as a failed request response instead of a connection-killing raise.
