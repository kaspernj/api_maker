Generated frontend models now type attributes that aren't model columns. A resource can declare the JavaScript type of such an attribute with `attributes :seconds_left, jsdoc_type: "number | null"`, and the generated accessor gets `/** @returns {number | null} */` instead of `/** @returns {any} */`. Attributes without a declaration keep the previous behaviour: the type is derived from the database column, translated attributes become `string | null`, and anything else stays `any`.
