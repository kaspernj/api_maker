Fixed the `/api_maker/commands` envelope crashes from older clients: a request without a `pool` section used to crash with `KeyError: key not found: "pool"` inside the authentication-divergence check, and a command name carrying the old array-of-entries envelope crashed with `TypeError` in `Array#to_h`. Both are now covered by the pool shape validation: the request answers 400 with the offending path and received class (`type: malformed_command_request`) before any command or auth-reconciliation logic runs, with the same redacted log line and rejection counter as other malformed payloads.
