Follow-up to the column default type cast: only boolean, integer and float defaults are cast now. Casting every column type made a time-only default gain a date that was never in the database — `"00:03:00"` came out as `"2000-01-01 00:03:00 +0100"` — and gave a timestamp default a timezone the column does not have, while a decimal default serialises as a string either way. Any other column type now keeps its default exactly as the database reports it.
